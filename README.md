# [VSCode Toolbox](https://toolbox.trenlok.com) website

## Tech Stack

- [Nuxt](https://nuxt.com)
- [Vue](https://vuejs.org)
- [Scss](https://sass-lang.com)

## Setup

Enable Corepack and install dependencies:

```bash
corepack enable
pnpm install
```

## Development

Start the development server on [localhost:3000](http://localhost:3000):

```bash
pnpm dev
```

Start the development server and expose it on the local network:

```bash
pnpm dev:public
```

Run type checking:

```bash
pnpm typecheck
```

Run linting:

```bash
pnpm lint
```

Format scripts and styles:

```bash
pnpm format
```

## Production

Build the application for production:

```bash
pnpm build
```

Generate a static version:

```bash
pnpm generate
```
